# ハヤト — iPhoneだけで音声会話できるAIエージェント

iPhoneに話しかけると、画面の中の相棒「ハヤト」が表情豊かに声で答えます。
調べもの、メモ、やることリストの管理を、会話しながら任せられます。パソコンは要りません。

ハヤトは熱くてまっすぐな相棒キャラクター（一人称は「俺」、タメ口）。ヘッドセットにスーツ姿のデフォルメ立ち絵で、
話すと口が動き、まばたきし、会話の内容に合わせて表情（笑顔・ワクワク・真剣・考え中・驚き・困り顔・しんみり）が変わります。

- 頭脳: Claude（Anthropic の Claude API を iPhone から直接呼び出す）
- 声: iPhoneに内蔵された音声認識と読み上げ（追加料金なし）
- 形: iPhoneのホーム画面に追加してアプリのように使う Web アプリ（PWA）。GitHub Pages で無料公開

## できること

| 話しかけ方の例 | ハヤトがすること |
|---|---|
| 「今日のニュースで大事なのは？」「明日の東京の天気は？」 | Web検索して要点を口頭で報告 |
| 「牛乳を買うのをメモして」 | メモとして保存（後で「買い物メモある？」で呼び出せる） |
| 「やることに企画書の提出を追加、期限は月末」 | タスクに登録。「やること教えて」で読み上げ |
| 「企画書、終わったよ」 | タスクを完了に |
| 「私の好きな食べ物、覚えてる？」 | 過去のメモを探して答える |

背景のリングと服のラインは状態で色が変わります。青: 待機・聞き取り中、橙: 分析中（考え中・検索中）、緑: 話している。
話している最中にマイクを押すと、割り込んで次の話を聞き取ります。「連続会話」をオンにすると、返答のあと自動で聞き取りを再開します。

## はじめかた（全部 iPhone でできます）

### 1. Claude API キーを用意する

1. Safari で [console.anthropic.com](https://console.anthropic.com) を開き、アカウントを作る
2. 「Billing」でクレジットカードを登録し、クレジットを購入する（まずは $5 程度で十分です）
3. 「Limits」で月の利用上限を設定しておくと安心です
4. 「API Keys」→「Create Key」でキーを作り、表示された `sk-ant-...` をコピーする（この画面でしか表示されないので、メモアプリなどに控えておく）

料金は使った分だけで、ふつうの会話なら1回あたり数円〜十数円ほどです（Web検索を使うと少し上がります）。

### 2. ハヤトを公開する（GitHub Pages・最初の1回だけ）

1. Safari で GitHub のこのリポジトリ（kankokei-alt/hayato）を開く
2. 「Settings」→ 左のメニューの「Pages」（スマホ表示で見つからなければ、Safari の「ぁあ」→「デスクトップ用Webサイトを表示」）
3. 「Build and deployment」の Source を **Deploy from a branch** にする
4. Branch で `claude/practical-ritchie-fehn47` と `/docs` を選び、「Save」
5. 1〜2分待つと、ページ上部に `https://kankokei-alt.github.io/hayato/` と表示されます

### 3. iPhoneにハヤトを入れる

1. Safari で `https://kankokei-alt.github.io/hayato/` を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のハヤトのアイコンから起動すると設定画面が開くので、手順1のAPIキーを貼り付ける。呼ばれ方も好きに設定
4. 「閉じる」を押し、マイクボタンを押して話しかける（初回はマイクと音声認識の許可を求められます）

> URLを知っている人がページを開くことはできますが、APIキーは各自のiPhoneの中にしか保存されないので、他の人があなたのキーやメモを使うことはできません。

## iPhoneでうまくいかないとき

| 症状 | 対処 |
|---|---|
| 「音声認識が使えないようです」と出る | iPhoneの設定 → Siri で Siri（音声入力）をオンにする。ホーム画面アプリ版で使えない場合は、Safariで同じURLを開いて使うか、左下のキーボードボタン → キーボードのマイクキーで話して送信 |
| 「マイクが許可されていません」 | 設定 → アプリ → Safari → マイク を「許可」に |
| 「APIキーが正しくないようです」 | 設定でキーを貼り直す（前後に空白が入っていないか確認） |
| 「APIの残高が足りないようです」 | console.anthropic.com の Billing でクレジットを追加 |
| 声が小さい・受話口から聞こえる | マイク使用直後にiPhoneが通話用スピーカーに切り替えることがあります。音量ボタンで上げるか、イヤホンを使う |
| 声が機械的 | 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語 で「拡張」や「プレミアム」の声をダウンロードし、ハヤトの設定で選ぶ |
| 話の途中で切られる | 1.4秒黙ると話し終わりとみなします。続けて話すか、キーボード入力を使う |

## データについて

- APIキー、メモ、タスク、会話の流れは **このiPhoneの中（ハヤトのアプリ専用の保存領域）** にだけ保存されます
- ホーム画面のアプリと Safari で開いたページは保存領域が別です。普段はホーム画面のアプリを使ってください
- 機種変更に備えて、設定の「メモとタスク → 保存」でときどきバックアップしてください（「ファイルに保存」でiCloud Driveに置けます）。新しいiPhoneでは「読込」で戻せます
- 会話の流れは「会話ログ → 新しい会話」でリセットできます（メモとタスクは残ります）

## カスタマイズ（開発する人向け）

```
src/          ハヤトの頭脳（TypeScript）
  agent.ts    Claude との会話とツール実行のループ
  persona.ts  ハヤトの人格（システムプロンプト）と表情タグの指示
  tools.ts    メモ・タスクのツール
docs/         公開されるアプリ本体（GitHub Pages がここを配信する）
  agent.js    src/ をまとめたもの（npm run build で生成）
  app.js      画面・音声認識・読み上げ・表情タグの処理
  character.js ハヤトの立ち絵（SVG）と表情・まばたき・口パク
```

`src/` を変更したら次のコマンドで `docs/agent.js` を作り直してコミットします。

```bash
npm install
npm run build
npm run serve   # http://localhost:8080 で確認
```
